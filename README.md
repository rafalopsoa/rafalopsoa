# Rafaela Lopes Soares

QA Sênior em sistemas regulatórios e de compliance integrados ao BACEN, à CVM e ao SISBAJUD/CNJ, com 5 anos anteriores na B3 (SINACOR). Em transição para SDET, aplicando em código o mesmo rigor de sistemas regulados: idempotência, trilha de auditoria, controle de acesso e mascaramento de dados.

## Projetos em destaque
- **[projeto-stockbroker](https://github.com/rafalopsoa/projeto-stockbroker)** — motor de negociação de corretora em C#/.NET 8, com Clean Architecture, DDD, TDD e controle de concorrência em SQL Server.
- **[api-core-banking](https://github.com/rafalopsoa/api-core-banking)** — API de core banking em Node.js/TypeScript, com TDD, JWT e logs de auditoria imutáveis.
- **[petshop-cats-api-testing](https://github.com/rafalopsoa/petshop-cats-api-testing)** — suíte de testes de API no Postman (GET e POST) sobre Mock Server, com 8 cenários mapeados no Zephyr, validação de contrato e schema em JavaScript e 18 asserções em execução regressiva.

# Rafaela Lopes Soares

**QA Sênior · Testes de backend, APIs REST e integrações · Sistemas financeiros regulados · Em transição para SDET**

Há 8 anos testo sistemas regulatórios e de compliance integrados ao BACEN, à CVM e ao SISBAJUD/CNJ, usados por mais de 200 instituições financeiras. Antes, foram 5 anos na B3, no SINACOR, em pós-negociação de Renda Variável e Derivativos. No trabalho atual, implantei do zero a validação de QA de 3 sistemas que antes eram validados apenas pela sustentação.

Este perfil reúne o meu portfólio de automação: aqui levo para o código o mesmo cuidado com regra de negócio, rastreabilidade e dados que aplico nos testes do dia a dia.

## No dia a dia de QA

- Testes funcionais, de regressão, integração, exploratórios e UAT, com foco em backend, banco de dados e regras de negócio
- Validação de contratos e payloads de APIs REST no Postman
- SQL em Oracle PL/SQL e SQL Server para validar dados e investigar falhas entre sistemas
- Planos e cenários em BDD/Gherkin, com rastreabilidade entre requisito, caso de teste e defeito (Azure DevOps e TestLink)
- Geração de massas de teste com SQL e IA generativa (Claude, Gemini), com cerca de 30% menos tempo de preparação
